\section{Linear function approximation}
Feature vector:
\[
    \text{For each } s \in\Sc, \phi(s) \in \R^d, \phi(s) = (\phi_1(s), \phi_2(s), \dots, \phi_d(s))^T
\]
Value function is approximated as, $V(s; w) = w^T \phi(s)$, where $w \in \R^d$ is the weight vector. Typically, $d \ll |\Sc|$. Value function approximation is linear in $w$.

\section{Weighted norm and contraction}
$T_\pi$ is a contraction w.r.t. $\norm{\cdot}_\infty$, but not w.r.t. $\norm{\cdot}_2$. $\Pi$ is non-expansive w.r.t. $\norm{\cdot}_2$, but expansive w.r.t. $\norm{\cdot}_\infty$.
How do we ensure that the iteration $V_{k+1} = \Pi T_\pi V_k$ will converge? Define the weighted $L^2$ norm, $\norm{V}_{2,\mu} = \E_{s\sim\mu}[V^2(s)]$ where $\mu$ is a probability distribution over $s$.

Let $f : \R^n \to \R$ be a convex function and let $X$ be a random vector. Then, $f(\E[X]) \leq \E[f(X)]$.

\subsection{Approximation error}
$\Pi T_\pi$ is a contraction mapping. So, it has a unique fixed point $\bar{V}_\pi$. The iteration $V_{k+1} = \Pi T_\pi V_k$ will converge to $\bar{V}_\pi$. What is the approximation error $\norm{V_\pi - \bar{V}_\pi}_{2,\mu}$?
\subsubsection{Proposition (approximation error)}
\[
    \norm{\Pi V_\pi - V_\pi}_{2,\mu} \leq \norm{\bar{V}_\pi - V_\pi}_{2,\mu} \leq \frac{1}{\sqrt{1-\gamma^2}} \norm{\Pi V_\pi - V_\pi}_{2,\mu}
\]
