\chapter{Introduction}
Deep learning is a subarea of machine learning, just as machine learning is a subarea of artificial intelligence. In artificial intelligence, 
we want to learn all kinds of topics about how to create and understand intelligence using computer systems. In this broad area, there is a particular 
method called machine learning where we use lots of data to train a machine, so the machine may learn how to solve a problem. Deep learning is a particular
kind of machine learning where we use deep neural networks for learning. \\
